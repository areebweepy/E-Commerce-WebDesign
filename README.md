# 🛍️ E-Commerce Frontend – Coza Store Inspired (Web Engineering Lab)

This project is a **custom-built frontend of an e-commerce website**, developed as part of the **Web Engineering Lab**. It is **visually inspired by** the [Coza Store](https://colorlib.com/wp/template/coza-store/) template by Colorlib, but **coded entirely from scratch** — no external code or frameworks were used.

---

## ✨ Features

- Fully static multi-page layout (HTML + CSS + JS)
- 🖼️ Home, Shop, Product, and Contact pages
- 🎞️ Custom JavaScript carousel with tuned transition timings
- 🧩 Product cards with category-based **filtering**
- ✏️ Built-in **edit and search** interface for product interaction
- 🖥️ Fixed-size layout designed for a specific laptop resolution
- ❌ Not responsive (no media queries or mobile support)

---

## 🛠️ Tech Stack

| Component        | Technology               |
|------------------|---------------------------|
| Markup           | HTML5                     |
| Styling          | CSS3                      |
| Interactivity    | JavaScript (Vanilla JS)   |
| IDE Used         | Visual Studio Code        |

---

## 🎯 Project Goals

- Recreate the visual layout of a professional e-commerce site using pure frontend tech
- Build all UI and logic manually (including carousels and filters)
- Practice DOM manipulation, layout structure, and interaction design
